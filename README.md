# Clyvora QR Studio

A simple QR code studio for creating, styling and exporting codes directly in your browser.

## Start the app

Requirements: Node.js 20 or later.

```bash
npm install
npm run dev:web
```

Open the local address printed in the terminal. The studio works without an account or server.

## What it can do

- Create QR codes for websites, text, Wi-Fi, contacts, email, phone, SMS, locations and events.
- Customize a code in a separate workspace with styles, patterns, corners, logos, frames and labels.
- Export PNG, SVG or PDF, copy SVG source or copy a PNG image.
- Undo and redo changes, and save codes or editable project files in this browser.
- Generate up to 100 codes from pasted lines or a single-column CSV.
- Read QR codes from local PNG, JPEG or WebP images. Decoded URLs are never opened automatically.
- Keep QR content on your device while creating and exporting codes.
